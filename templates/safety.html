Algorithm Summary

1. Initialization:

Work = Available
Finish[i] = false (for all i)

2. Find process Pi where:

Finish[i] == false AND Need[i] ≤ Work

3. If found, simulate completion:

Work = Work + Allocation[i]
Finish[i] = true
Append Pi to safe sequence

4. Repeat Step 2 until:

  • All processes finish → SAFE STATE
  • No process can finish → UNSAFE STATE
